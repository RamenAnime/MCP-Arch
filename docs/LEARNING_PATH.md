# Kyoto Learn OS - Learning path (0% to Rosetta-ready)

## Philosophy

You learn Japanese the way children learn a first language: sound, then simple words, then reading and writing, then full sentences. English stays available at first and fades as you level up inside `kyoto-learn`.

## Writing systems (all three)

| Order | System | When | Goal |
|-------|--------|------|------|
| 1 | Hiragana ひらがな | Levels 1-2 | Read every native word ending and grammar chunk |
| 2 | Katakana カタカナ | Level 3 | Read loanwords, brands, game terms |
| 3 | Kanji 漢字 | Levels 4-5 | Read signs, menus, core nouns and verbs |

## Levels (in `kyoto-learn`)

| Level | Focus |
|-------|--------|
| 0 | How Japanese works (sounds, word order, three scripts) |
| 1-2 | Hiragana read + write (romaji drills, paper tracing) |
| 3 | Katakana |
| 4-5 | Starter kanji with sentences |
| 6 | Core vocabulary |
| 7 | Short grammar (particles) |
| 8 | Immersion mode (more Japanese in prompts) |
| 9 | Kyoto dialect (どす / まっす / おおきに) |
| 10 | Bridge to Rosetta Stone or any audio app |

## Daily 15-minute loop

1. **5 min** - kana drill in terminal (`kyoto-learn` menu 2 or 3)
2. **5 min** - vocab or kanji (menus 4-5)
3. **5 min** - say one sentence out loud; write it on paper

## When you are ready for Rosetta Stone

- Read hiragana and katakana slowly without hesitation
- Know at least 60 kanji and 100 words
- Understand は・が・を in short sentences
- Study 15 minutes daily for 30+ days

Run level 10 inside `kyoto-learn` for the full checklist.
